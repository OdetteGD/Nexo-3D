# Lua editor smoke test

This project is generated by `.github/workflows/lua-editor-smoke.yml` in CI. It verifies that a tools-enabled Godot editor starts with the Lua module, loads `main.lua` as a `LuaScript` resource attached to a `Node`, and invokes the attached script's `_ready()` callback at runtime. It is a headless editor/runtime integration test; visual interaction with the New Script dialog still needs a manual editor session.
